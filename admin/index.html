Dein Anthropic API Key für Claude
Maximale Antwortlänge (256-4096)
Alexa Integration
z.B. alexa2.0 oder alexa2.1
Gerätesteuerung
Leer lassen für alle Räume, z.B.: Wohnzimmer, Küche, Schlafzimmer
Erweiterter System-Prompt (Optional)
Optional: Erweitere den Standard-Prompt mit eigenen Anweisungen. Leer lassen für Standard-Prompt.
Hilfe

So funktioniert der Adapter:

  1. Spracheingaben vom Alexa2 Adapter werden empfangen
  2. Claude analysiert den Befehl und erkennt die Absicht
  3. Das entsprechende ioBroker-Objekt wird gesteuert

Beispiel-Befehle:

  • "Schalte das Licht im Wohnzimmer ein"
  • "Stelle die Heizung auf 22 Grad"
  • "Dimme die Lampe auf 50 Prozent"

Manueller Input:

Schreibe in den State llm-controller.0.manualInput um Befehle direkt zu senden.
